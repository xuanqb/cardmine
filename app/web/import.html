导入数据

支持导入 Anki 牌组包、Markdown 题库文件，或直接粘贴面经原文交由 AI 拆解。

导入 apkg

支持 .apkg / .colpkg。按正面文本幂等导入：重复导入不会产生重复卡片； 已有卡片背面为空时，会用导入内容补全。媒体文件会一并落盘。

点击或拖拽选择 .apkg / .colpkg 文件 媒体资源会自动提取并保存

导入 Markdown 题库

支持 .zip（Markdown + 图片文件夹）或 .md / .markdown。按 ## 分章节、### 分题目： 题干作为正面、正文作为背面，导入为 draft 卡片；章节拆成子模块，图片会复制进媒体库。 重复导入按正面幂等：已存在且背面非空会跳过，背面为空则补全。

点击或拖拽选择 .zip / .md 文件 支持附带相对路径图片的压缩包
